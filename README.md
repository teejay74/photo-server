# Личная фотогалерея

Минималистичный веб-интерфейс для локального каталога фотографий. Работает на Python 3, оригиналы не изменяет.

## Возможности

- EXIF-дата, модель камеры, размеры изображения и GPS-координаты;
- инкрементальный индекс SQLite без повторного чтения неизменённых файлов;
- избранное, синхронизированное между браузерами;
- пользовательские альбомы;
- пользователи с ролями «просмотр», «редактор» и «администратор»;
- серверные сессии, Argon2id-хеширование паролей и защита изменяющих запросов CSRF-токеном;
- карта фотографий на OpenStreetMap;
- локальная копия Leaflet без загрузки JavaScript и CSS со стороннего CDN;
- поиск точных копий и визуально похожих кадров без автоматического удаления;
- расширенные фильтры и подборка «В этот день»;
- массовое добавление в избранное и альбом, скачивание выбранного в ZIP;
- автоматические проверенные резервные копии SQLite;
- защита индекса файлом-маркером при отключённом или не смонтированном диске;
- адаптивная временная шкала, поиск и полноэкранный просмотр со свайпом, увеличением и перемещением снимка;
- отдельная группа «Без даты» для файлов без EXIF-даты и даты в имени файла.
- неразрушающее исправление названия, описания, даты, координат и ручных тегов;
- длительность, разрешение, дата и кодеки видео, серверные постеры и совместимый веб-просмотр MOV/HEVC;
- локальный «Умный каталог»: скриншоты, документы, панорамы, кадры с текстом,
  тёмные, светлые, монохромные и насыщенные фотографии;
- фоновый инкрементальный анализ изображений и OCR на русском и английском;
- поиск по распознанному тексту и смысловым признакам — без отправки фотографий во внешние сервисы.
- локальное распознавание и группировка лиц с возможностью дать человеку имя,
  исправить отдельное лицо или объединить группы;
- автоматические аватары и список отмеченных людей в полноэкранном просмотре фотографии;
- поиск снимков по нескольким людям: все выбранные на одном фото или любой из них;

## Запуск в Docker

На сервере должны быть установлены Docker Engine и Docker Compose. Клонируйте репозиторий и создайте локальный файл настроек:

```bash
git clone https://github.com/teejay74/photo-server.git
cd photo-server
cp .env.example .env
```

Откройте `.env` и задайте:

- `PHOTO_DIR` — абсолютный путь к фотографиям на сервере;
- `PHOTO_USER` и `PHOTO_PASSWORD` — логин и пароль первого администратора;
- `APP_UID` и `APP_GID` — UID и GID владельца каталога фотографий.

Создайте в корне каталога фотографий защитный маркер. Без него приложение не будет сканировать хранилище и удалять отсутствующие записи из индекса:

```bash
touch /srv/photos/xiaomi-13t/Camera/.photodom-storage
chown photos:photos /srv/photos/xiaomi-13t/Camera/.photodom-storage
```

Например, если каталог принадлежит пользователю `photos`, значения можно узнать так:

```bash
id -u photos
id -g photos
```

Защитите файл с паролем и запустите приложение:

```bash
chmod 600 .env
docker compose up -d --build
docker compose ps
```

После запуска галерея доступна по адресу `http://IP-СЕРВЕРА:8080`. Порт можно изменить через `WEB_PORT` в `.env`.

При первом запуске приложение создаёт в SQLite администратора из `PHOTO_USER` и `PHOTO_PASSWORD`. В дальнейшем пароль хранится только как Argon2id-хеш и меняется в окне аккаунта. Изменение этих двух переменных в `.env` уже созданного пользователя не переименует и пароль ему не поменяет. Администратор может создавать и отключать пользователей, сбрасывать им пароли и назначать роли:

- **Просмотр** — просмотр, поиск и скачивание фотографий;
- **Редактор** — дополнительно управляет избранным и альбомами;
- **Администратор** — дополнительно управляет пользователями и резервными копиями.

Система не позволит отключить или понизить роль последнего активного администратора.

Оригиналы подключаются к контейнеру только для чтения. Миниатюры сохраняются в Docker volume `thumbnail-cache`, индекс, избранное, альбомы и учётные записи — в `gallery-data`, а резервные копии SQLite — в отдельном `gallery-backups`. Эти данные сохраняются при пересборке контейнера. Посмотреть журнал или остановить приложение можно командами:

Редактор или администратор может открыть фотографию и нажать кнопку с карандашом, чтобы исправить её сведения. Правки сохраняются только в SQLite, участвуют в поиске, временной шкале, фильтрах и карте, но не изменяют EXIF или содержимое оригинала. Кнопка «Вернуть данные из файла» удаляет все ручные правки выбранного файла.

```bash
docker compose logs -f
docker compose down
```

Обновление приложения:

```bash
git pull
docker compose up -d --build
```

## Запуск без Docker

```bash
export PHOTO_ROOT=/srv/photos/xiaomi-13t/Camera
export PHOTO_USER=photos
export PHOTO_PASSWORD='change-me'
python3 server.py --host 0.0.0.0 --port 8080
```

Pillow опционален. С ним приложение создаёт и кэширует уменьшенные копии; без него в сетке отображаются оригиналы.

Для расширенной поддержки видео нужны `ffprobe` и `ffmpeg`; в Docker-образ они уже включены. Метаданные видео читаются при индексации, а постер создаётся при первом появлении ролика в сетке. Совместимые MP4/WebM отдаются без изменений. Для MOV, HEVC и других неподдерживаемых браузером комбинаций при первом просмотре создаётся кэшированная MP4-копия H.264/AAC шириной не более 1920 пикселей. Оригинал не изменяется и остаётся доступен по кнопке скачивания.

## Переменные окружения

- `PHOTO_ROOT` — каталог оригиналов.
- `PHOTO_MARKER_FILE` — имя обязательного файла-маркера в корне `PHOTO_ROOT` (по умолчанию `.photodom-storage`).
- `PHOTO_CACHE` — каталог кэша миниатюр.
- `PHOTO_DB` — путь к базе SQLite с индексом, избранным, альбомами, пользователями и сессиями.
- `PHOTO_SCAN_INTERVAL` — период проверки новых и изменённых файлов в секундах.
- `PHOTO_SMART_OCR` — распознавать текст на фотографиях локальным Tesseract (по умолчанию `true`).
- `PHOTO_SMART_DELAY` — пауза между фоновыми заданиями в секундах (по умолчанию `1.5`); увеличьте её, чтобы ещё сильнее ограничить нагрузку CPU.
- `PHOTO_SMART_OCR_LANGUAGES` — языки OCR (по умолчанию `rus+eng`).
- `PHOTO_SMART_OCR_TIMEOUT` — максимальное время OCR одной фотографии в секундах.
- `PHOTO_VIDEO_TRANSCODE` — создавать совместимые MP4-копии неподдерживаемых видео (по умолчанию `true`).
- `PHOTO_VIDEO_MAX_WIDTH` — максимальная ширина совместимой копии (по умолчанию `1920`).
- `PHOTO_BACKUP_DIR` — каталог резервных копий SQLite.
- `PHOTO_BACKUP_INTERVAL` — интервал автоматических копий в часах.
- `PHOTO_BACKUP_RETENTION` — количество хранимых копий.
- `PHOTO_USER` и `PHOTO_PASSWORD` — данные только для автоматического создания первого администратора в пустой базе. Для нового развёртывания используйте пароль не короче 10 символов.
- `PHOTO_SESSION_DAYS` — срок действия серверной сессии в днях (по умолчанию 30).
- `PHOTO_COOKIE_SECURE` — установите `true`, когда сайт работает через HTTPS; при обычном локальном HTTP оставьте `false`.
- `PHOTO_HOST`, `PHOTO_PORT` — адрес и порт.

При переносе фотографий на другой диск сначала скопируйте весь каталог вместе с `.photodom-storage`, настройте постоянное монтирование диска, проверьте наличие маркера и только после этого меняйте `PHOTO_DIR` и запускайте контейнер. Эндпоинт `/health` возвращает `503`, если маркер отсутствует; существующий индекс, избранное и альбомы при этом сохраняются.

Умный каталог обрабатывает только фотографии, по одному файлу за раз. Видео не анализируются. Очередь и готовые результаты находятся в той же SQLite-базе, поэтому после перезапуска обработка продолжается с сохранённого места. При добавлении или изменении файла он автоматически попадает в очередь; запускать полную переиндексацию вручную не требуется.

## Распознавание лиц

Поиск лиц работает локально внутри контейнера: детектор YuNet находит лицо, а SFace создаёт числовой вектор, по которому похожие лица объединяются в группы. Оригиналы фотографий никуда не отправляются. В SQLite сохраняются координаты лица, вектор и принадлежность к группе; миниатюры лиц находятся в обычном кэше.

Откройте «Умный каталог» → «Люди». Редактор или администратор может присвоить группе имя, объединить две группы и перенести ошибочно распознанное лицо в другую или новую группу. Ручное объединение допускает несколько изображений одного человека на одном снимке — например, отражение, коллаж или повторную детекцию. Первичная обработка большой библиотеки выполняется в фоне и может занять несколько часов; сайт в это время продолжает работать. Новые и изменённые фотографии добавляются в очередь автоматически.

Чтобы найти совместные фотографии, отметьте несколько карточек людей и выберите «Все выбранные». Режим «Любой выбранный» покажет фотографии, где присутствует хотя бы один из отмеченных людей. На карточках также отображается постоянный номер группы, который можно использовать при объединении и переносе лиц.

Кнопка полной переиндексации лиц удаляет имена и все ручные исправления, поэтому используйте её только при необходимости. База SQLite с результатами входит в обычные резервные копии приложения.

Docker-образ загружает зафиксированные версии моделей из OpenCV Zoo и проверяет их SHA-256. Копия лицензии Apache 2.0 сохраняется рядом с моделями в образе.
